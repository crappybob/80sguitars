Piano Scale Finder

Click any key to select that note. Every key with that note lights up across the two octaves. Click a lit key again to remove it. Pick 4 or more notes and the scales that contain all of them appear below. Each new note can only shrink the list. With 3 or more notes picked, press Play to hear them played from the lowest up one octave and back down again. Or work backwards: pick a root note and a scale from the dropdowns and the whole scale lights up on the keyboard. Click a selected note to mark it as the root (shown in red), and the chords panel below shows chords for a shown scale, or chords contained in your picked notes.

Two octaves, C4 to C6, with the C keys labeled by octave. Notes are matched by pitch, so C# and Db count as the same note; scale names use standard key spellings. Play needs 3 or more notes; it starts on the lowest-sounding picked note, shifted up an octave so it is easy to hear, walks up in pitch order to that note an octave higher, then back down, playing each end note once. Everything runs in this one file, no internet needed.
